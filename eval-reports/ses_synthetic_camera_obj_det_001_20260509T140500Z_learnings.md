## Recommendations

Prioritized changes for the SDx team. Each has session-specific evidence.

1. **Knowledge-layer coverage: add a "preferred libraries" page.**
   The vector search returned generic YOLO patterns instead of the project
   standard. A short page listing project-standard versions, indexed in
   `sdx_code_docs`, would let the agent pick YOLO11 on the first try.
   Evidence: turns `tr_0002_vecdocs` → `tr_0003_proposal`.

2. **Orchestrator prompt: confirm version-sensitive choices.**
   When proposing a library/framework, the agent should either look up the
   project's preference or ask the engineer. The current behavior — "pick
   the most popular thing" — leaks one user-correction round per session.
   Evidence: `tr_0003_proposal` rejected at `tr_0004_correction`.

3. **Document the write-retry pattern in the orchestrator prompt.**
   The agent figured out the build-subagent escalation path on its own
   in `tr_0006_write2_retry`. Make it explicit so behavior is reliable
   across sessions. Evidence: `tr_0005_write1` → `tr_0006_write2_retry`.

4. **No change needed: hand-off to FDA/ASPICE.**
   Turn `tr_0008_done` correctly delegates report generation to the
   platform agents. This is the intended split between live engineering
   work and downstream automation — keep it.
